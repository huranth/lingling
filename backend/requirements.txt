# Lingling backend dependencies.
#
# Versions are pinned exactly. `>=` ranges meant a fresh `pip install` could pull
# a future major and break the app with no code change on our side -- FastAPI
# resolved 0.110 -> 0.140 on this machine that way. Bump deliberately, then run
# `python tests/test_routing.py` before committing the change.
#
# httpx handles every outbound call to OpenCode Zen and models.dev; the [socks]
# extra plus socksio are what let it speak to the local WARP SOCKS5 proxies.
# h2 is optional: when installed, Lingling negotiates HTTP/2 with the upstream,
# which reuses a single tunneled connection for concurrent streams and cuts
# first-token latency. Without it the code silently falls back to HTTP/1.1.
fastapi==0.140.0
uvicorn[standard]==0.51.0
httpx[socks]==0.28.1
socksio==1.0.0
h2==4.2.0
pydantic==2.13.4
